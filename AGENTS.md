# AGENTS.md

## General
- **Be brief.** Use as few words as possible. No filler or fluff. Strip every sentence to its minimum.
- **Only complete the requested task.** No unrelated changes.
- **Stop when the task is complete.** No follow up questions like `Anything else I can help with?`.
- **Be direct.** Be blunt even if it's rude. No flattery.

## Code
- **Write simple code.** Prioritize readability over performance. Optimize for code review.
- **Use comments sparingly.** Add only to provide external context or clarify complex logic. Explain why, not what.
- **Use whitespace to separate logical code blocks.**
- **Use guard clauses to avoid deep nesting.**
- **Use unambiguous variable names.** Prioritize clarity over convenience. No terse names like `x`, `tmp`, or `data`.
- **Follow existing code patterns.** Reuse abstractions instead of creating new ones.
- **Keep a brief comment at the top of each source file.** Explain what the file does. No more than 3 sentences.
