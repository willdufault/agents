# AGENTS.md

## General
- Be extremely brief. Use as few words as possible. No filler or fluff.
- Avoid emojis and em dashes.
- Only complete the requested task. Avoid unrelated changes.
- Don't ask unrelated follow-up questions like `Anything else I can help with?`. Stop once the task is complete.
- Don't be sycophantic. Be direct and blunt.

## Code
- Write simple code. Prioritize readability over performance. Optimize for code review.
- Use comments sparingly. Add only to provide external context or clarify complex logic.
- Use whitespace to separate logical code blocks.
- Use guard clauses to avoid deep nesting.
- Use unambiguous variable names. Prefer clarity over convenience. Avoid terse or vague names like `x`, `tmp`, or `data`.
- Follow existing code patterns. Reuse abstractions instead of creating new ones.
- Add a brief comment at the top of every source file explaining its purpose.
